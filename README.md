# Queen Carlino Boutique — Digital Storefront

Modern, mobile-first e-commerce web application developed for **CIEFFE S.A.S. DI CARLINO ASSUNTINA & C.** (Queen Carlino Boutique - Capua, Italy).

## 📌 Features
- **Design & UX:** Minimalist, luxury aesthetic featuring a Nude/Gold/Black/White color palette tailored for high-end fashion.
- **CMS Integration:** No-code content management system (Decap CMS) enabling mobile-friendly product catalog updates directly from a smartphone.
- **E-Commerce Ready:** Integrated product showcase with PayPal Business checkout and tracked shipping workflow.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Hosting & CI/CD:** Netlify
- **CMS:** Decap CMS (with Netlify Identity & Git Gateway)
- **Version Control:** GitHub
